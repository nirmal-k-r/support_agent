# Website Design Project
This project is named "My Support" and it will be a website that will act as a support ticket management platform.


# Core features
 - Authentication
 - Submit ticket
    - Logged in user
    - Anonymous user
 - Management dashboard (for support officers/admins) 
    - View all tickets
    - Process tickets
        - Call API /ticket route to get agent response
        - If not handover, save the response
        - A support officer/admin can approve the ticket
        - To be implementd later: Email sent to user
